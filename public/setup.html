YOUR SERVER · YOUR DATA

Set up your dashboard

Run the server once, then point each app to its address.

Full setup guide ↗
01

Start the server

On a computer that can stay online, install Python 3, clone the project, and run:

git clone https://github.com/crz02/DashBoard-For-AllDevices.git
cd DashBoard-For-AllDevices
./start_server.sh

Open the dashboard at http://localhost:8080/dashboard.

02

Connect your devices

Install and open Statuser, then enter your server address in the app’s Settings. On your home Wi-Fi, use your server’s local IP, for example:

http://192.168.1.50:8080

Use the same User ID on devices you want grouped together.

03

Connect from anywhere

To report over cellular or another network, set up a secure tunnel to your server. Keep remote access limited to a service you trust.
