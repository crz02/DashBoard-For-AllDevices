Setup Instructions

Connect Device

Choose an OS to copy the reporting command

Run in Terminal to send a one-time report:

curl -s -X POST "http://localhost:8080/api/report" -H "Content-Type: application/json" -d '{"device_id":"macbook","name":"My MacBook","platform":"macos","battery_level":88}'

For automatic background reporting, install the Statuser Desktop App — it runs silently in your menu bar and reports every few minutes automatically.

Run in Windows PowerShell:

powershell.exe -ExecutionPolicy Bypass -File .\agents\windows\report_battery.ps1 -DashboardUrl "http://YOUR_SERVER_IP:8080" -DeviceId "windows-laptop"

In iOS Shortcuts app, create a shortcut with action:

Get Battery Level → Get Contents of URL

POST http://YOUR_SERVER_IP:8080/api/report

Trigger automatically under Automation → Charger Connected.

Send HTTP POST from Tasker / MacroDroid / Termux:

POST http://YOUR_SERVER_IP:8080/api/report

Run in Terminal to send a one-time report:

curl -X POST "http://localhost:8080/api/report" -H "Content-Type: application/json" -d '{"device_id":"linux-laptop","platform":"linux","battery_level":75}'

Auto-report every 5 min via crontab:

*/5 * * * * curl -s -X POST "http://localhost:8080/api/report" -H "Content-Type: application/json" -d "{\"device_id\":\"linux-laptop\",\"platform\":\"linux\",\"battery_level\":$(cat /sys/class/power_supply/BAT0/capacity 2>/dev/null || echo 100)}" >/dev/null

Add the crontab line via: crontab -e
